This pipeline was developed to run a GWAS of pituitary adenoma within an inhouse cohort and then meta-analyse with downloaded summary statistics from UK Biobank, All of Us, and FinnGen.

The files should be ran as follows:
1. genotypeharmoniser.sh
2. call_QC_commands.sh
3. Population_stratification_steps.txt
4. RUN IMPUTATION HERE 
5. REGENIE_step1.sh
6. REGENIE_step2.sh
7. metal.txt
